# Pocket Arcade V2 original artwork

All twelve SVG cover illustrations and the sixteen board piece/building/lot SVG assets in this directory were created specifically for Pocket Arcade during this V2 redesign. They are original vector compositions made from geometric paths, gradients, and shapes; they contain no stock images, third-party artwork, emoji, external fonts, or network resources.
